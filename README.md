# 123Movies

**Open-source video streaming app for 123Movies fans — clean native UI, fast playback, zero ads.**

Customizable watchlists, floating nav menu, update prompts, QR sharing and a support-developer section — fully transparent and community-driven.

## Features

- **Free HD movies & series streaming** — browse, search, watch
- **Zero ads** — no banners, popups or trackers
- **Watchlist** — save favourites locally
- **Floating nav menu** — quick access to Home, Search, Updates, Profile
- **In-app updates** — UpdateManager + UpdatePromptModal
- **QR sharing** — share titles via QR code canvas
- **Feedback & settings screens** — built-in support flow

## Screens

Home · Search · Profile · Settings · Feedback · Updates

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Extras:** QrCodeCanvas, FloatingNavMenu, UpdateManager
- **Build:** Gradle KTS, compileSdk 36, minSdk 24, Java 11

## Getting Started

```bash
git clone https://github.com/the-anonymous-vigilante/123Movies.git
cd 123Movies
cp .env.example .env
# GEMINI_API_KEY=your_key_here
```

Open in Android Studio → Sync → Run, or:

```bash
./gradlew assembleDebug
```
